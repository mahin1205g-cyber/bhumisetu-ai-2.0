## 🌟 প্রকল্পের ওভারভিউ (Project Overview)

**ভূমিসাথী (BhumiSathi / LandGuard AI)** হলো বাংলাদেশের ডিজিটাল ভূমি সেবা ইকোসিস্টেমের জন্য প্রস্তুতকৃত একটি সমন্বিত, বিশ্বস্ত ও কৃত্রিম বুদ্ধিমত্তা-চালিত ওয়েব প্ল্যাটফর্ম। এটি হ্যাকাথনের ৩টি প্রধান জাতীয় সমস্যাকে একটি একক সরকারি পোর্টাল ইন্টারফেসে একীভূত করেছে:

1. **P2: ডিজিটাল দলিল ও মালিকানা যাচাই (Deed & Ownership Verification):** দলিল নম্বর, সাল, দাগ, খতিয়ান ও মৌজার তথ্যের সাথে সাব-রেজিস্ট্রি বালাম রেকর্ডের ক্রস-চেক, এআই টেক্সট এক্সট্রাকশন (OCR), গরমিল শনাক্তকরণ এবং ডিজিটাল ভেরিফাইড কিউআর সনদ।
2. **P4: স্মার্ট ই-নামজারি ওয়ার্কফ্লো (Smart E-Namjari Workflow):** ৪-ধাপের নির্দেশিত নামজারি ফরম, খসড়া সংরক্ষণ, অনন্য ট্র্যাকিং নম্বর (`MUT-2026-DHK-XXXX`), রিয়েলটাইম টাইমলাইন ট্র্যাকার এবং সহকারী কমিশনার (ভূমি) / এসি ল্যান্ডের অনুমোদন ও পর্যালোচনা ড্যাশবোর্ড।
3. **P5: জমি কেনার আগে প্রাক-ক্রয় নাগরিক যাচাই (Citizen Due Diligence):** বায়না বা ক্রয়ের চুক্তির পূর্বে প্লটের স্বত্ব ধারাবাহিকতা, একাধিকবার বিক্রি, ৩০ দিনের মধ্যে অস্বাভাবিক দ্রুত হস্তান্তর, অধিগ্রহণ নোটিশ বা দেওয়ানি বিরোধ যাচাই করে ০-১০০ ঝুঁকি স্কোর এবং ৫টি জরুরি করণীয়সহ ডিউ ডিলিজেন্স রিপোর্ট।

## 🚀 চালানোর বিস্তারিত নির্দেশনা (Running & Setup Guide)

### ১. পূর্বশর্ত (Prerequisites)
- **Node.js** (v18 বা পরবর্তী)
- **Python** (v3.10 বা পরবর্তী)
- **Git**

### ২. রিপোজিটরি ক্লোন করুন
```bash
git clone https://github.com/mahin1205g-cyber/bhumisetu-ai.git
cd bhumisetu-ai
```

### ৩. ব্যাকএন্ড সেটআপ ও চালু করার নিয়ম (FastAPI)

> ব্যাকএন্ড এখন **PostgreSQL (Neon)** ব্যবহার করে — `DATABASE_URL` ছাড়া সার্ভার চালু হবে না।

```bash
# ডিপেন্ডেন্সি ইনস্টল করুন
pip install -r requirements.txt

# .env-এ DATABASE_URL সেট করুন (Neon/Postgres connection string)

# ব্যাকএন্ড ফোল্ডারে প্রবেশ করে সার্ভার চালু করুন
cd backend
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```
👉 ব্যাকএন্ড এপিআই চালু হবে: **`http://127.0.0.1:8000`** (Swagger API Docs দেখতে পাবেন `/docs`-এ)

### ৪. ফ্রন্টএন্ড লাইভ সার্ভার চালু করার নিয়ম (React + Vite)
আলাদা একটি নতুন টার্মিনাল খুলে নিচের কমান্ডগুলো রান করুন:
```bash
cd frontend
npm install
npm run dev
```
*(উইন্ডোজ পাওয়ারশেলে কোনো রেস্ট্রিকশন আসলে `npm.cmd run dev` ব্যবহার করুন)*

👉 ব্রাউজারে খুলুন: **`http://localhost:5173`**  
*(ফ্রন্টএন্ড স্বয়ংক্রিয়ভাবে ব্যাকএন্ড এপিআই প্রক্সি করে এবং রিয়েলটাইম হট-রিলোড সাপোর্ট করে)*

### ৫. স্বয়ংক্রিয় টেস্ট রান করুন
```bash
pytest tests
```
*(সবগুলো টেস্ট স্বয়ংক্রিয়ভাবে সফলভাবে পাস করবে)*

## 🤖 এআই অ্যাসিস্ট্যান্ট কনফিগারেশন (AI Assistant Configuration)

চ্যাট অ্যাসিস্ট্যান্ট (ভূমিসেতু AI) একটি **লাইভ LLM API** দিয়ে চলে। কোনো API key
কনফিগার করা না থাকলে অ্যাসিস্ট্যান্ট ভুয়া বা হার্ডকোড উত্তর দেয় না—বরং স্পষ্টভাবে
জানায় যে সার্ভারে AI প্রদানকারী কনফিগার করা নেই।

### ১. প্রদানকারী নির্বাচন (Provider)

| Provider | Environment variables |
| --- | --- |
| Google Gemini (প্রস্তাবিত) | `GEMINI_API_KEY` (ঐচ্ছিক: `GEMINI_MODEL`, ডিফল্ট `gemini-2.5-flash`) |
| OpenAI | `OPENAI_API_KEY` (ঐচ্ছিক: `OPENAI_MODEL`, ডিফল্ট `gpt-4o-mini`) |
| OpenAI-compatible (Groq, DeepSeek, OpenRouter…) | `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `OPENAI_MODEL` |

দুটি key একসাথে থাকলে `LLM_PROVIDER=gemini` বা `LLM_PROVIDER=openai` দিয়ে একটি বেছে নিন।
অন্যান্য ঐচ্ছিক ভেরিয়েবল: `LLM_TIMEOUT_SECONDS` (ডিফল্ট ৩০), `LLM_MAX_OUTPUT_TOKENS` (ডিফল্ট ১০২৪)।

### ২. লোকাল সেটআপ

```bash
cp .env.example .env          # Windows PowerShell: Copy-Item .env.example .env
# .env ফাইলে GEMINI_API_KEY অথবা OPENAI_API_KEY পূরণ করুন
pip install -r requirements.txt   # python-dotenv সহ
cd backend && uvicorn main:app --reload --port 8000
```

`.env` ব্যাকএন্ড চালু হওয়ার সময় স্বয়ংক্রিয়ভাবে লোড হয় (python-dotenv ইনস্টল থাকলে) —
রিপো রুটের `.env` অথবা `backend/.env`, দুই জায়গাতেই রাখা যায় (রুট `.env`-এর অগ্রাধিকার)।
`.env` কখনো কমিট করবেন না — `.gitignore`-এ এটি বাদ দেওয়া আছে।

### ৩. Vercel-এ ডিপ্লয় (Deployment)

**প্রয়োজনীয় Environment Variables** (Project → Settings → Environment Variables):

| Variable | Value |
| --- | --- |
| `DATABASE_URL` | Neon/Postgres connection string (`...?sslmode=require`) — **বাধ্যতামূলক** |
| `GEMINI_API_KEY` | Google Gemini key (AI chat-এর জন্য) |
| `CORS_ORIGINS` | ফ্রন্টএন্ড আলাদা ডোমেইনে থাকলে সেটির URL (কমা দিয়ে একাধিক) |

**এক প্রজেক্টে ফ্রন্টএন্ড + ব্যাকএন্ড (প্রস্তাবিত):**

1. Vercel → **Add New Project** → এই রিপোটি ইমপোর্ট করুন।
2. **Root Directory** খালি রাখুন (রিপো রুট)।
3. বাকি সেটিং ডিফল্ট রাখুন — `vercel.json` নিজেই `framework: fastapi` সেট করে,
   ফ্রন্টএন্ড বিল্ড করে `public/`-এ রাখে এবং `app.py`-কে একমাত্র Function হিসেবে চালায়।
4. উপরের env vars যোগ করে **Deploy** করুন।
5. যাচাই করুন:
   ```bash
   curl https://<project>.vercel.app/api/chat/status
   # ব্রাউজারে: https://<project>.vercel.app/  এবং  /docs
   ```

> পুরোনো `api/index.py` + `rewrites` ভিত্তিক সেটআপ Vercel-এর বর্তমান FastAPI
> রানটাইমে কাজ করে না (সব request ভুল path নিয়ে 404 হয়) — তাই সেটি সরানো হয়েছে।

**আলাদা প্রজেক্ট (ফ্রন্টএন্ড ও ব্যাকএন্ড আলাদা):**

- **ব্যাকএন্ড:** Root Directory = `backend` (কোনো `vercel.json` লাগবে না, `main.py`
  স্বয়ংক্রিয়ভাবে FastAPI entrypoint হিসেবে ডিটেক্ট হয়)। env: `DATABASE_URL`,
  `GEMINI_API_KEY`, `CORS_ORIGINS=https://<frontend-domain>`।
- **ফ্রন্টএন্ড:** Root Directory = `frontend`, env:
  `VITE_API_URL=https://<backend-domain>/api`।

> Vercel-এ SQLite ব্যবহার করা যায় না (ফাইলসিস্টেম read-only) — `DATABASE_URL`
> (Neon/Postgres) সবসময় লাগবে।

### ৪. যাচাই (Verify)

```bash
curl http://127.0.0.1:8000/api/chat/status
```
`"ai_configured": true` এবং `"provider": "Google Gemini (gemini-2.5-flash)"` দেখালে
লাইভ মডেল সক্রিয়। অথবা Swagger `/docs` → `POST /api/chat/message`-এ যেকোনো প্রশ্ন পাঠান।

### ৫. নিরাপত্তা ও আচরণ

- API key শুধুমাত্র ব্যাকএন্ডে থাকে; ব্রাউজারে বা API response-এ কখনো পাঠানো হয় না।
- আবেদনের অবস্থা শুধুমাত্র লগ-ইন করা মালিক (বা অনুমোদিত কর্মকর্তা/অ্যাডমিন) দেখতে পান;
  অন্যের ট্র্যাকিং নম্বর জিজ্ঞেস করলে ডেটা ছাড়াই অনুরোধ প্রত্যাখ্যাত হয়।
- কথোপকথনের শেষ ১২টি মেসেজ (সর্বোচ্চ ~১২,০০০ অক্ষর) মডেলে পাঠানো হয়; "নতুন চ্যাট"
  বাটনে ক্লিয়ার করলে পুরোনো প্রসঙ্গ বাদ পড়ে।
- প্রদানকারী timeout/rate-limit/নেটওয়ার্ক ব্যর্থ হলে ব্যবহারকারী পুনরায় চেষ্টা (Retry)
  অপশনসহ স্পষ্ট ত্রুটি বার্তা দেখেন—কোনো নকল উত্তর তৈরি হয় না।

## 📊 ডেটার উৎস ও ডাটাবেজ (Data Sources & Methodology)

### ১. ডেটার প্রকৃতি ও উৎস (Synthetic Land Records Dataset)
- হ্যাকাথনের প্রদর্শনী ও প্রোটোটাইপিংয়ের জন্য বাংলাদেশের বাস্তব ভূমি রাজস্ব কাঠামোর সাথে শতভাগ সামঞ্জস্য রেখে একটি **সিন্থেটিক ডেমো বালাম ডাটাবেজ** তৈরি করা হয়েছে।
- **মৌজা ও উপজেলা কাঠামো:** ঢাকা জেলার মিরপুর উপজেলার অন্তর্গত 'পাইকপাড়া' মৌজাকে মডেল হিসেবে নিয়ে বিএস (BS), আরএস (RS), এবং এসএ (SA) খতিয়ান নম্বর, দাগ নম্বর এবং বালাম ভলিউম রেজিস্টারের ডেটা প্রস্তুত করা হয়েছে।
- **বাস্তবসম্মত দৃশ্যকল্পসমূহ:**
  - *স্বত্ব ধারাবাহিকতা সম্পন্ন সঠিক দলিল:* বৈধ সাফা কবলা দলিল, হাল সন পর্যন্ত দাখিলা ও খাজনা পরিশোধিত রেকর্ড।
  - *মালিকানা গরমিল রেকর্ড:* বিক্রেতার নামের ভুল বানান, ভুয়া ওয়ারিশ দাবিদার ও বেআইনি পাওয়ার অফ অ্যাটর্নি।
  - *ঝুঁকিপূর্ণ রেকর্ড:* দেওয়ানি আদালতের স্বত্ব মামলা বিচারাধীন দাগ, ৩০ দিনের মধ্যে অস্বাভাবিক দ্রুত হস্তান্তর (Flipping Anomaly), এবং সরকারি অবকাঠামো প্রকল্পের অধিগ্রহণ প্রস্তাবিত জমি।

### ২. ডেটা নিরাপত্তা ও প্রাইভেসি প্রটোকল (Privacy & Compliance)
- এই প্রজেক্টে সরকারের কোনো সংরক্ষিত, লাইভ বা সাধারণ নাগরিকের ব্যক্তিগত গোপনীয় ডেটা ব্যবহার করা হয়নি। 
- ব্যবহৃত সকল এনআইডি, ফোন নম্বর এবং নাম সম্পূর্ণ কৃত্রিম (Synthetic) এবং প্রতিযোগিতার নীতিমালা ও জাতীয় সাইবার নিরাপত্তা আইন মেনে তৈরি।

## 🤖 এআই টুল ব্যবহারের ঘোষণা (AI Tool Usage Declaration)

হ্যাকাথনের স্বচ্ছতা নীতিমালার আলোকে এআই টুল ও অ্যালগরিদম ব্যবহারের বিস্তারিত ঘোষণা নিচে তুলে ধরা হলো:

### ১. অ্যাপ্লিকেশনে ব্যবহৃত বিল্ট-ইন এআই ও অ্যালগরিদমসমূহ (Embedded AI Engines)
- **Scikit-learn (Isolation Forest Anomaly Detection):** জমির মূল্য এবং ৩০ দিনের মধ্যে অস্বাভাবিক দ্রুত হস্তান্তরের অস্বাভাবিক প্যাটার্ন (Land Flipping Anomaly) শনাক্ত করতে ব্যবহৃত হয়েছে।
- **Rule-Based Conflict Resolution Engine:** স্বত্ব ধারাবাহিকতা বিচ্ছিন্নতা (Broken Chain of Title), দ্বৈত বিক্রি (Duplicate Deed on Same Plot) এবং অধিগ্রহণ সতর্কতা যাচাইয়ের জন্য স্বয়ংক্রিয় লজিক ইঞ্জিন।
- **PyPDF ও রেগুলার এক্সপ্রেশন (Regex OCR Parser):** আপলোডকৃত দলিলের পিডিএফ থেকে দলিল নম্বর, ক্রেতা-বিক্রেতার নাম, দাগ ও খতিয়ান নম্বর স্বয়ংক্রিয়ভাবে এক্সট্রাক্ট করার জন্য।
- **GPT-Land Assistant (Generative Advisory):** সাধারণ নাগরিকের বিভিন্ন ভূমি সংক্রান্ত প্রশ্ন ও পরিভাষার তাৎক্ষণিক রিয়েলটাইম পরামর্শক।

### ২. ডেভেলপমেন্ট ও কোডিং প্রক্রিয়ায় এআই অ্যাসিস্ট্যান্সের ঘোষণা
- প্রজেক্টের আর্কিটেকচার ড্রাফটিং, টাইপোগ্রাফি ফিক্স এবং রেসপনসিভ ইউআই পলিশিংয়ের ক্ষেত্রে আধুনিক কোডিং অ্যাসিস্ট্যান্ট (যেমন: Google Antigravity / Gemini) এর সহায়তা নেওয়া হয়েছে।
- প্রজেক্টের মূল বিজনেস লজিক, স্কিমা ডিজাইন, হ্যাকাথন সমস্যা সমাধান আর্কিটেকচার এবং ভূমি পরিভাষা সম্পূর্ণ দলের নিজস্ব গবেষণার ফসল।
